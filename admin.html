Kích Hoạt Đăng Nhập Google Thật

Để mở cửa sổ đăng nhập trực tiếp từ máy chủ Google (accounts.google.com) giống như các trang web và ứng dụng hiện nay, hệ thống cần Google Client ID (OAuth 2.0) của dự án.

  1. Vào console.cloud.google.com và đăng nhập Gmail.
  2. Bấm Create Credentials (Tạo thông tin xác thực) → Chọn OAuth client ID.
  3. Application type chọn Web application.
  4. Mục Authorized JavaScript origins thêm: http://localhost:5252
  5. Bấm Create → Copy chuỗi Client ID dán vào ô trên là xong!
Bạn đang truy cập qua Localhost

Mã QR được in ra sẽ chứa địa chỉ localhost. Khi sinh viên quét bằng điện thoại sẽ bị báo lỗi không truy cập được.

Cách khắc phục: Kết nối điện thoại và máy tính vào cùng mạng Wi-Fi. Tìm địa chỉ IP của máy tính (ví dụ: 192.168.1.15), sau đó trên trình duyệt máy tính, hãy truy cập Admin qua đường dẫn IP đó: http://[IP-của-máy]:5252/admin.html rồi tiến hành in mã QR.
